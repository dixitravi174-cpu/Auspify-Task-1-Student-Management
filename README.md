# Task 1: Student Management System

A web-based Student Management System built using **Python (Flask)** and **SQLite**, developed for the Auspify Technologies Software Development Internship.

---

## 📌 Project Features
- **Create Student**: Add student records with Roll Number, Name, Email, Course, and Phone.
- **Read / View Students**: Real-time tabular display of all registered students.
- **Update Student**: In-place modification of existing student records.
- **Delete Student**: Removal of records with confirmation prompt.
- **Persistent Storage**: Lightweight SQLite database integration (`students.db`).
- **Responsive UI**: Clean Bootstrap 5 interface.

---

## 🛠️ Tech Stack
- **Backend**: Python 3.12, Flask
- **Database**: SQLite3
- **Frontend**: HTML5, CSS3, Bootstrap 5, Jinja2 Templates
